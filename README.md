### ⚠️ গুরুত্বপূর্ণ সতর্কতা (KM-3802-04 বোর্ড)
ফোল্ডারে থাকা **KM-3802-04 机板** বোর্ডটি একটি **মশার ব্যাট (Mosquito Racket)-এর হাই-ভোল্টেজ ও চার্জিং সার্কিট**।
* **সাবধান:** এই বোর্ডের কোনো তার ফোনে লাগাবেন না! এতে ১০০০V-৩০০০V হাই ভোল্টেজ বা ২২০V এসি ডাইরেক্ট সংযোগ থাকে যা ফোন সম্পূর্ণ পুড়িয়ে ফেলবে।
